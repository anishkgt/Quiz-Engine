# Quiz-Engine
An HTML-CSS based Quiz Engine for practice

This quiz engine can help you prepare of any exam. Add questions into the engine as you study. The engine supports Practice/Test modes with untimed and timed sessions respectively. A set of 27 questions specific to ISA/IEC 62443 Cybersecurity Fundamentals Specialist are already set 

The interface is simple,
  1. Open the HTML file
  2. Add/change questions for the test/practice
  3. Add/change Domains
  4. Choose number of Questions
  5. Chooe time limit (Test mode only). Practice in indefinite.
  6. Choose domains.
  7. Start Quiz

Enjoy ! Happy learning.
