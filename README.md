# Quiz-Engine
An HTML-CSS based Quiz Engine for practice

This quiz engine can help you prepare of any exam. Add questions into the engine as you study. The engine supports Practice/Test modes with untimed and timed sessions respectively.
https://github.com/anishkgt/Quiz-Engine/blob/main/Quiz%20Engine.png
The interface is simple. Open the HTML file, add/change questions for the test/practice.
